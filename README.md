# Potato 配音工具

一个最小、独立运行的 Edge-TTS 网页配音工具。

## 功能

- 在网页中输入文本
- 选择中文、英文、韩文或日文音色
- 外语音色自动显示译文，并使用译文生成配音
- 按语言筛选音色，避免下拉列表混杂
- 调整 0.5×–2.0× 语速
- 使用 `[[pause:800ms]]` 或 `[[pause:1.5s]]` 插入精确停顿
- 使用 `|`、`||`、`|||` 快速插入短、中、长停顿
- 在线试听并下载 MP3
- 无需 API Key

## 启动

```bash
cd /Users/mengfou/Projects/tools/potato
./start.sh
```

浏览器会打开 <http://127.0.0.1:8765>。按 `Control+C` 停止服务。

首次启动时，`uv` 会自动创建独立 Python 环境并安装 `edge-tts`。

## 说明

工具本身在本机运行，但 Edge-TTS 合成需要联网访问 Microsoft 的语音服务。生成文件保存在 `outputs/`。

## 停顿语法

```text
大家好，[[pause:800ms]]今天介绍一个新工具。[[pause:1.5s]]让我们开始吧。
```

- `|`：停顿 300ms
- `||`：停顿 700ms
- `|||`：停顿 1.2s
- `[[pause:800ms]]`：精确毫秒停顿
- `[[pause:1.5s]]`：精确秒数停顿
- 如果需要朗读 `|` 字符，请输入 `\|`

单次停顿范围为 50ms–10s，停顿总计最多 60 秒。自定义停顿依赖系统中的 FFmpeg。
